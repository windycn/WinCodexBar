## WinCodexBar 0.2.1

本次更新集中修复界面缩放、删除确认弹窗遮挡和刷新时的卡顿，并加入离开模式。

- 初次显示前应用 DPI 缩放；删除账号时先收起置顶托盘面板，再显示确认框。
- 工作台刷新时复用账号行控件，背景渐变复用缓存；托盘刷新动画限制在图标区域重绘。
- 后台刷新节奏对齐 macOS 版：当前账号默认每分钟检查，其他账号每 5 分钟检查一次。
- 保持唤醒默认关闭，可从托盘菜单或快捷面板开启。
- 新增黑屏离开模式：只显示黑色覆盖层，不锁屏、不改变电源策略；鼠标移动、点击或按键即可退出，Codex 和后台任务继续运行。
- 黑屏前可等待 5、15 或 30 秒；快捷面板按钮补充文字说明，托盘图标提供六种可预览样式。
- 发布 x64、x86、arm64 三种自带 .NET 运行时的更新包，并提供 SHA256 校验清单。

从 0.2.0 及更新版本可使用内置更新器直接升级。更新器会先校验匹配架构的安装包并备份账号与设置，再替换程序文件并重启。
