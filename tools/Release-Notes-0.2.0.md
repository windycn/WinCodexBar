## WinCodexBar 0.2.0

本次重做设置布局，统一 Fluent 风格、内置中英文字体与 Microsoft Fluent UI System Icons，并修复按钮、删除确认和窗口开关冲突。

- 屏幕适配：默认跟随显示器 DPI，可手动选择 100%–300%；窄窗口自动切换紧凑导航，设置卡片上下排列，操作区不再挤出窗口。
- 重置卡只读展示剩余次数、各张到期时间；账号详情显示精确额度重置日期、时间与时区。不提供使用或兑换重置卡的功能。
- 额度按账号实际提供的窗口显示；没有 5 小时额度时只显示 7 天额度，托盘图标同步使用 7 天数据。缺失数据与真实 0% 分开处理。
- 托盘：可选额度圆环、剩余百分比、经典图标；单击立即展开，双击打开工作台。用量扫描移至后台并复用缓存，减少重复绘制和等待。
- 更新：启动后和每 6 小时检查正式版；确认后下载匹配架构、验证 SHA256、备份数据、覆盖并重启。文件替换失败时尝试回滚旧程序。
- 模型：加入 GPT-6 Astra / Sol / Luna，读取本机 Codex 模型缓存补充选择；保留旧模型与自定义价格，修复模型配置误写入 TOML profile 的问题。
- 重置窗口：修正 CodexRadar 摘要解析，当前开启状态优先于过期预测；显示来源与缓存状态，获取中或不可用时保留提示。
- 数据：升级和删除账号不删除 Codex 会话；新版首次启动和自动更新前备份账号、设置。

### 安装与升级

一般 Intel / AMD 电脑选择 `win-x64`；Windows on ARM 选择 `win-arm64`；32 位系统选择 `win-x86`。三个 ZIP 均自带 .NET 运行时。

从 0.1.x 首次升级请先退出旧版，再解压新包到可写目录。原有 `%USERPROFILE%\.codexbar` 数据会保留。升级至本版后，可使用内置检查更新。请保留包中的许可证文件。

`SHA256SUMS.txt` 提供三种架构包的校验值。Windows 自动回归已覆盖设置各页、手动缩放、删除确认、窗口复用，以及实际 PowerShell 覆盖和失败回滚。实体混合 DPI 显示器热插拔及不同显卡环境尚未实机核验。
