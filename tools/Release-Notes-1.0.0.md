# WinCodexBar 1.0.0

WinUI 3 工作台、圆角托盘面板、生图工作台、模型质量检测、本机历史、系统通知以及更新流程。

黑屏离开改为 Windows 原生空闲关屏路径，关屏后恢复原电源设置；后台任务保持运行，鼠标或键盘可唤醒显示器。此路径用于规避部分现代待机设备上旧关屏命令造成的唤醒循环。

生图工作台默认关闭，每次使用一个选定的 Codex 账号，不启动网页服务或账号代理。支持最多 10 张图片、参考图粘贴，以及将历史或刚生成的图片转为可编辑 SVG。

账号与设置保存在用户目录。首次运行完整 ZIP 中的 `WinCodexBar.exe` 会按需安装随包提供的微软签名 Windows App Runtime，然后启动工作台。请先退出旧版，再将 ZIP 解压到可写目录；不要从压缩包中直接运行。
