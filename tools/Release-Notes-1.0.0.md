# WinCodexBar 1.0.0

WinCodexBar 把 Codex 多账号额度、Token 与会话统计，以及图像创作工具放进 Windows 托盘和 WinUI 3 工作台。本版提供 x64、x86、ARM64 三种架构的完整 ZIP 包。

## 账号与托盘

- 保存和切换多个 Codex 账号，查看 5 小时与 7 天额度、重置时间、健康状态及重置卡到期时间。切换账号后会提醒重启 Codex。
- 托盘默认显示圆环数字，可在设置中预览并切换其他样式。速览面板提供账号、用量、会话、保持唤醒和常用操作。
- 支持 OpenAI 官方授权、复制授权链接、账号导入与导出。默认兼容 codexbar JSON，并提供其他格式选项。导出文件包含可使用账号的凭据，请妥善保存。
- 额度警戒、重置窗口、账号切换、创作任务及更新等事件可发送 Windows 通知。

## 创作与检测

- 生图工作台默认关闭，开启后在独立窗口中选定一个 Codex 账号使用。支持提示词编辑和粘贴、模型与思考强度选择、画幅、分辨率、质量、一次最多 10 张，以及多张参考图上传或粘贴。
- 转可编辑 SVG 可从生图图库、刚生成的图片、本机文件或剪贴板选图；单独选择账号、文本模型、思考强度和补充要求。SVG 结果独立入库，支持预览、打开文件及复制代码。
- 图像与 SVG 共用最多 6 项并行任务队列。两个图库都采用缩略图卡片，保留提示词、时间、模型等信息，可自定义目录，管理索引与回收站。
- 模型质量检测提供预设及自定义题目，直接显示 HTML 结果并保留本机记录。
- 模型及思考强度等选项保留上次选择；生图、SVG 和检测的使用量汇总到 Token 活动。

## 统计、桌面与更新

- Token 活动展示每日、每周、每月使用、连续活跃、峰值和费用估算；会话分析展示数量、模型分布与最近会话。费用按公开价格估算，并非官方账单。
- 黑屏离开在所有显示器上覆盖黑色画面，鼠标或键盘输入可恢复；可选立即或延时进入。黑屏期间临时保持唤醒，退出后恢复原设置。
- 设置提供通知、启动项、托盘样式、界面缩放、模型参数、桌面快捷方式、GitHub 项目入口及当前版本。
- 可手动检查正式版更新，或开启自动检查及静默更新。下载包经 SHA256 校验，安装前备份账号与设置；静默安装等待窗口关闭且任务完成。

## 安装

下载对应架构的 `WinCodexBar-1.0.0-win-*.zip`，解压到独立、可写目录，再运行 `WinCodexBar.exe`。请勿直接在压缩包内运行。首次启动会按需安装随包提供、经微软签名的 Windows App Runtime。

此前下载过 1.0.0 的用户，请重新下载并覆盖安装本次发布包；旧版更新器只比较版本号，无法识别同版本替换包。账号与设置保存在用户目录，不在程序安装目录。
